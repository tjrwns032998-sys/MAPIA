# 월광 살롱 (MAFIA)

친구들과 실시간으로 즐기는 마피아 게임방입니다. 앤티크 살롱 분위기의 단일 HTML 파일(`mafia.html`)로 만들어져 있습니다.

## 규칙
- 4~12명이 참여하고, 인원에 따라 마피아·의사·경찰·시민이 자동 배분됩니다.
- 밤: 마피아는 함께 한 명을 고르고, 의사는 살릴 사람, 경찰은 조사할 사람을 고릅니다.
- 아침: 죽은 사람이 마피아인지 시민인지만 공개됩니다.
- 낮: 5분 토론 후(또는 과반이 원하면 먼저) 투표합니다. 과반 득표자는 30초 최후 발언 뒤 찬반 투표를 받습니다.
- 마피아가 생존자의 절반 이상이면 마피아 승리, 마피아를 모두 찾으면 시민 승리입니다.

## 실행 방식
이 파일은 claude.ai 아티팩트의 실시간 기능(`db`, `room`, `user`)을 사용합니다. 아티팩트로 게시한 뒤 공유 메뉴에서 친구를 '참여자' 권한으로 초대해야 함께 플레이할 수 있습니다. 일반 웹 서버에서 파일만 열면 멀티플레이는 동작하지 않습니다.
